# VGP Phase I dated trees

We dated the ROADIES v0.0.0 and ASTRAL v0.1.1 trees using [MD-CAT](mdcat/README.md). Branch lengths are given in **millions of years (Ma)**.

Updated independent MD-CAT trees are the primary results below; bottom-up alternatives are linked from each analysis page. The reference topologies are distributed in [VGP tree-release](https://github.com/VGP/vgp-tree-release). This repository records their calibrations, dated trees, and visualizations. The [calibration documentation](../calibrations/README.md) provides the fossil justifications. The [main list](../calibrations/master_calibrations.csv) contains 108 constraints, with 105 mapped to ROADIES, 100 to ASTRAL, and 97 shared. The [reference-tree documentation](../trees/README.md) describes the undated topologies, annotations, and APE node-numbering files.
