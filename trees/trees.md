# Tree visualizations

These are just adaptations of [roadies_v1.1.16b.nwk](https://github.com/VGP/vgp-trees/blob/main/phase-1/) to add node numbers and other visual aids. Key initial pieces are roadies_v1.1.16b.numbers and roadies_v1.1.16b.numbers.scientific with node numbers added, in both Newick and PDF. The PDFs will be our initial reference points for assigning calibrations across clades with an internally consistent numbering system.

Run `Rscript trees/roadies_v1.1.16b.numbers.R` from the repository root to regenerate the ROADIES numbered accession/scientific Newick files and their reference PDFs. The script validates annotation mappings, preserves source branch-length precision, and leaves the source tree unchanged. PDFs use equally spaced cladogram depths.

The ASTRAL-Pro input is `astralpro.l6p1.tre` (565 tips). Run `Rscript trees/astralpro.l6p1.numbers.R` from the repository root to regenerate `astralpro.l6p1.numbers.nwk`, `astralpro.l6p1.numbers.scientific.nwk`, and their `.pdf` reference plots. Numbering follows ape's internal-node indices, 566–1129, and is specific to this topology. Derived Newick files replace the input's internal labels with node numbers while preserving its rooting, topology, branch lengths, and tip identifiers; scientific-name files change only the tip labels additionally. The input remains unchanged. PDFs are cladograms for inspecting node numbers, not branch-length plots.

Annotation additions for this tree were verified against NCBI: [GCA_000001405.5, Homo sapiens GRCh37.p4](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_000001405.5/), [GCA_000001635.9, Mus musculus GRCm39](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_000001635.9/), and [GCF_037038585.1, Patagioenas fasciata bPatFas1.hap1](https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_037038585.1/). Their species-level fields reuse the existing same-species annotation rows; `AssemblyId` records the verified assembly name, while unverified `asmId` and `UCSC_comName` fields are blank. Existing rows are preserved.

The script explicitly maps `kxProAnne1` through the existing `AssemblyId` field to the `GCA_040939525.1` annotation row for Protopterus annectens, retaining `kxProAnne1` as the original tip identifier. Human and mouse each have two tips; both members of each duplicate scientific-name pair receive their original accession suffix. These mappings are for labels only and do not substitute defining taxa in calibrations.
